# KpopQuiz Off-Site Promotion Plan

The single highest-ROI SEO lever left is off-site presence: AI engines and Google
weight where you are mentioned, not just your own pages (brands are cited ~6.5x
more via third-party sources than their own domain). This is manual outreach, not
code. Work it weekly.

Golden rule: be a real participant first, link only when it genuinely helps. Never
spam-drop. Authentic Reddit / Quora / community presence doubles as AI-SEO because
those are among the most-cited sources by ChatGPT and Perplexity.

No em dashes in any copy you post on behalf of the brand.

---

## 1. Communities (ongoing, highest value)

- **r/Kpop_Verse** (your own): post a quiz/blind-test challenge a few times a week,
  weekly leaderboard, "quiz of the day". This is home base.
- **r/kpop**: huge but strict. Participate genuinely; only share when a thread
  truly calls for it. Read the rules first.
- **r/kpophelp, r/kpopthoughts**: lower-friction, answer questions, link when apt.
- **K-Pop Amino**: mobile-first, has quizzes/fan clubs natively. Your content fits.
- **Large K-pop Discord hubs** (chart/streaming/fan servers): partner, do not cold
  self-promo in general chat. Aim for a #partners exchange or mutual shoutout.
- Find more via The Hive Index K-pop list: https://thehiveindex.com/topics/k-pop/

## 2. Q&A (evergreen backlinks + AI citations)

- **Quora**: answer K-pop questions with depth; link naturally where relevant.
- **Reddit answers**: when someone asks "good kpop quiz?", give a real answer + link.
These persist for years and get surfaced by AI engines.

## 3. Launch / directory sites (one-time backlinks + traffic spike)

Layer these: smaller first, then the big ones.
- Uneed, BetaList, Indie Hackers, OpenHunts, Smol Launch, DevHunt
- AlternativeTo (list as an alternative to Sporcle's K-pop quizzes)
- Product Hunt (prep assets first), Hacker News "Show HN"
Reference list: https://graygrids.com/blog/product-hunt-alternatives

## 4. Visual / short-form (biggest organic ceiling)

- **Pinterest**: you already have the integration. K-pop + quizzes are huge there
  and it is a top referral source. Pin quiz cards + blind-test visuals consistently.
- **TikTok / YouTube Shorts / Instagram Reels**: "guess the K-pop song in 10s"
  blind-test clips are tailor-made to go viral. Link in bio. Highest upside channel.
- **Tumblr**: active K-pop fandom; share quizzes + results.

## 5. Code support (Claude Code can help these)

- Share buttons on every quiz/result/blind-test (with UTM tags).
- Dynamic OG share cards per quiz/group/blind test (better social CTR).
- A clean /about + /stats page to cite in directory submissions.
- Keep the Pinterest auto-pin flow healthy.

## 6. Cadence

- Daily: 1 post in r/Kpop_Verse + 1 short-form clip.
- Weekly: 1 Quora/Reddit genuine answer, 1 Pinterest batch, publish the weekly roundup.
- Monthly: 2-3 directory submissions, run the AI-visibility check (admin tracker).
