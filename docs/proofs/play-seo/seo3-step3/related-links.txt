Related-by-entity refinement (U4)
==================================
STATUS: existing implementation is the entity-max we can do today.
The quizzes table has no `tags` column and QuizSettings jsonb has no
era/album/member field. "Shared tags (era/album/member)" is NOT
computable without schema changes -> DEFERRED to O1 slice.

CURRENT related logic (page.tsx line 148):
  1. Fetch top 8 quizzes for the same group (ordered by plays).
  2. Filter out the current quiz.
  3. Top up with popular quizzes if fewer than 4 same-group results.
  4. Take up to 6.

This IS entity-based already: "same group" is the strongest entity link
we have without a tags column. No fake improvement was added on top.

New cross-links added (this step)
