# PERS report: Which character are you on otakuquiz.org (owner, 2026-10-26)

Branch o1/pers. The page /which-{series}-character-are-you of the anime build is the kpop engine and components with a quiz written by us per series.

## What was built
- Data: `docs/anime/data/personality/<series-slug>.json`, one quiz per series: `status`, `spoiler` (arc 0), eight questions of four answers (trait weights 0 to 5 on one
  to three of the six axes of the engine), 6 to 20 profiles (`character_slug`, `traits` = the six axes 0 to 100, `profile` = 2 to 4 lines to the reader, `ord`).
  Schema `scripts/anime/k1/personality.schema.json`; the rules and the SQL in `scripts/anime/k1/personality-data.mjs`.
- Death Note (the proof set): Light Yagami, L, Ryuk, Soichiro Yagami, Touta Matsuda, Kanzo Mogi (all spoiler level 0), 8 questions. Each character is the result of
  about 16.5 percent of the 65536 answer sheets.
- Loader: `data-load.mjs` reads the folder, `load-fixtures.mjs --data <dir>` writes the rows (`--only personality` writes only those). Rows: 8 questions in
  `personality_questions` (band of the group, see requests 3) and one `personality_profiles` row per character with `character_id`. Idempotent, stale rows removed.
- Launch: `L10-PERS-personality.sql` and its rollback, generated by `apps/quiz/e2e/o1/L1/content-sql.mjs` (published sets of loaded series only).
- Editorial check: a fifth kind of file `personality` (C1 schema and reach, C3 characters, C5 spoilers against the arc, C7 to C9, C11, C12 emoji and voice, C14).
- App: `lib/personality/{series,character-page,sets}.ts`, site-aware `data.ts` and `server.ts` (a guard on the build's site, the kpop path untouched), the twin
  page of `app/sites/[site]/(anime)/which-character/[group]`, the hub tile href and the anime sitemap.

## Decisions
- One quiz per series (the owner's brief) over the contract's one question set per site: stored in the existing tables with no DDL (requests 3).
- The Death Note set is `published`; flip `status` to `draft` to hold it (the rows load inactive and the page answers 404).
- The quiz arc is 0 and every result is a spoiler level 0 character: the page has no spoiler shield (TWINS row 14).
