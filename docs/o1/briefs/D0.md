# Brief D0: the design prototype (Wave 0, static, priority 1)

Read first: `O1/docs/o1/briefs/COMMON.md` (all of it). Reviewer profile: UX. Then the owner validates it (gate G5).
Size: 14 to 20 agent-hours (estimate).

## Goal
The pixel reference for every new screen of otakuquiz.org, fanquiz.org and the passport, and the kpopquiz.org deltas,
validated by the owner before any visual merge of Wave 2.

## Worktree
`ROOT/.claude/worktrees/o1-D0`, branch `o1/D0`, guard agent `D0`. Static HTML and CSS only, in
`design/o1-prototype/` (never shipped in the app, never imported by app code). No build, no dev server of the app.
To look at a page, open the file in a browser or serve the folder with `python3 -m http.server <your port>`.

## Rules specific to D0
- No image of a character, poster, logo or cover; no real fan photos. Placeholders are geometric.
- Real data only: numbers in frames are marked as fixture values or "New"; never an invented count presented as real.
- External resources: the Google Fonts stylesheet for M PLUS Rounded 1c is allowed in the prototype; nothing else
  from outside (no CDN scripts, no remote images).
