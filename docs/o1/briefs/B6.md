## Build
- GET /api/n/me (every site): 200 NetMe from rpc my_passport() plus passport_prefs (defaults when no row), Cache-Control private,
  no-store; 401 unauthenticated for a guest. Only client islands call it, after hydration; an anonymous page never calls it.
- POST /api/n/b (every site): body NetBeacon {dst, bridge, step} as JSON or text/plain, 2 KB at most; 204 always except 400 bad_request
  and 403 origin (Origin not in the network). Flag NEXT_PUBLIC_NET_BEACON off, or over the IP-hash limit (NET_IP_HASH_SALT): count nothing.
  Else rpc net_bridge_bump(src, dst, bridge, step, signed_in); for step land the row is (dst, SITE.id). Steps: NET_BEACON_STEPS
  (shown, click, land, dismiss, optin). Never store a user id or an IP.
- Q/lib/network/links.ts bridgeHref(dst, path, bridge) and editorialHref(dst, path); Q/lib/network/eligibility.ts eligibleFor(me, dst)
  and canShow(me, dst, id, caps, now?) (hidden beats membership; liked without membership is eligible; suggestions off disables all;
  dismissals expire; caps). Storage fq.net.caps.v1 (localStorage) and fq.net.via (sessionStorage), every access in try/catch.
- Q/components/network/net-link.tsx NetLink {dst, path, linkId, editorial?, className?, children}: a plain <a>, never next/link;
  editorial gives editorialHref, followed, no query; else bridgeHref with rel="nofollow", rendered in a client island after /api/n/me and
  canShow. The via catcher reads ?via= (VIA_RE) on landing, keeps it in fq.net.via and strips it from the URL.
- Menu (flag NEXT_PUBLIC_NET_MENU): in the account menu (Q/components/layout/ux-v1/ux-nav-actions.tsx through an optional prop), "Your
  sites" with the member's sites and levels from /api/n/me, each a NetLink; footer (flag NEXT_PUBLIC_NET_FOOTER): the one anonymous
  cross-site link of link-allowlist.json (kpop and anime to the hub home, followed, no query).
- Analytics: a beforeSend that drops ?via and identifiers, against the installed @vercel/analytics signature.
