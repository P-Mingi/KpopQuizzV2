Card anatomy
Five zones, one job: make the game obvious.
1
The preview is the real game state. Real member faces, three already named, four dashed slots still to fill, the live timer and the input with a caret. A fan reads the mechanic in under a second. This replaces the gradient tile with "ABC".
2
Title, then one hook in fan voice. Not a feature list. What you do and why it stings: "Miss one and the timer shows you who."
3
One honest stat, never four. Your best score if you have one, otherwise a fact about the format. No stat-slop rows.
4
One primary action. A single rose Play. The mode count is a quiet chip beside it, not a competing button. The verb changes per game: Play, Vote, Find a duel, Start ranking.
5
Every card is the same shape. Same preview height, same body rhythm, same shadow scale, so the grid reads as one family and the eye compares games, not layouts.
Build notesPreview area 196px on a cream surface; faces 58px at 12px radius with the site's border and card shadow; timer as an ink pill; title 18/800; hook 14 in txt2; stat 12/600 in txt3; Play = the site's btn.pri at 36px. All icons are one 2px stroke set at 14 to 18px. No emoji anywhere.
