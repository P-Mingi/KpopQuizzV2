# P8 requests to A0

None of these block P8 (each has a composed workaround inside P8's own files); they are the places where a
shared component would say it better.

## 1. Sheet title line box (low)

- What: `.ux-sh-h h2` uses `line-height: 1.4` (25.2px at 18px). The prototype's sheet titles (`.sh-h h3`) use the
  body line height 1.6 (28.8px).
- Why: P8's style capture of the `editor` state (v11/reports/P8/proto-styles.json, `#editor .sh-h h3`) differs on
  `line-height` only. No layout effect today (the header row is as tall as the 40 / 44px close button), so the
  P8 spec skips that one property with a comment.
- Prototype state: `editor` (also `signin`, `share`, `header-sheet`).

## 2. UxDropdown: show the picked value alone (optional)

- What: an option for the trigger to read "All groups" / "BTS" (the picked option's label) instead of
  "Group: BTS".
- Why: the community group menu of the prototype (`.fctl .dd`) shows the current value only. P8 composes
  `UxPopover` + `.ux-dd` + `.ux-mi` (menuitemradio, aria-checked) in `components/community/ux-v1/feed.tsx`
  (`GroupMenu`); it can switch to UxDropdown once it has the option.
- Prototype state: `community`.

## 3. PostCard: blog layout with the title beside the cover (optional)

- What: a `cover` slot (or `layout="blog"`) that renders the prototype's `.bwrap`: 200px cover on the left, title
  + excerpt on the right, cover on top on phones.
- Why: `PostCard` always renders the title above `children`. P8 places the pieces with a CSS grid on the card
  (`.p8-card-blog`, reading order unchanged: title, excerpt, cover link), measured equal to the prototype
  (title at +119.6px, pacts at +285.6px at 1440; cover 312 x 234 then title 24px under on phones).
- Prototype state: `community` (blog cards).
