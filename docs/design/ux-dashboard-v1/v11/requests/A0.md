### P4.md 3: `useUxMe()` can differ between SSR and the first client render

- Fixed in 7e01137. `useUxMe()` returns `null` on the server and during hydration (`useIsClient()`), whatever
  the module caches of `useMe()` / `refreshUxMe()` already hold; an island mounted after hydration still gets
  the cached value on its first render (no extra loading flash). `lib/auth/use-me.ts` is unchanged (shared,
  flag-off code). P4's own `useIsClient()` guard in `intro-islands.tsx` can stay or go.
- Proof: `/ux-v1/kit` section "viewer" renders `useUxMe()` text on the server and hydrates late on purpose
  (own Suspense boundary, code fetched once the `/api/auth/me` cache is filled). `kit.spec` asserts no
  hydration error as a guest and as the test user (read only, `guardWrites`), at 1440 and 390. The old hook
  fails the same 4 runs with "Hydration failed because the server rendered text didn't match the client".

### P10.md 1: the selected tab turns ink while hovered

- Fixed in e99892f: the hover colour applies to unselected tabs only
  (`.ux-utabs > button:not([aria-selected="true"]):hover, .ux-utabs > a:not([aria-current="page"]):hover`).
  `kit.spec` hovers the selected tab (pink-soft-ink), an unselected one (ink), clicks it and keeps the
  pointer on it (pink-soft-ink). The old rule fails at 1440 and 390 (rgb(31, 27, 23) instead of
  rgb(179, 48, 92)). P10's spec can measure with the pointer on the tab again.

### P1.md 1: focus the page H1 on client navigation

- Fixed in f11ec96 (`components/layout/ux-v1/ux-chrome-gate.tsx`, `UxRouteFocus`, mounted by the shell for
  every v11 page). It existed with a single 60 ms timer, which missed the H1 of routes with a `loading.tsx`
  (the skeleton commits first, the page streams in later). It now watches `#main` for the new H1 (up to 30 s),
  sets `tabindex="-1"` when the page did not, focuses it with `preventScroll`, and the a0.css rule keeps it
  ring-free. Not on the first load, not on query-only changes, and never after the fan moved focus.
  P1's `tabIndex={-1}` on the home H1 can stay.
- Proof: `shell.spec` "client navigation" (1440 nav links, 390 tab bar, a quiz behind `loading.tsx`, and
  Enter on a nav link from the keyboard).
