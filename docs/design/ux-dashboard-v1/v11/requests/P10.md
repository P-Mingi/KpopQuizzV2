# P10 requests to A0

## 1. Tabs: the selected tab turns ink while hovered

- What: in `src/styles/ux-v1/a0.css`, `.ux-utabs > button:hover, .ux-utabs > a:hover { color: var(--ux-ink); }`
  (specificity 0,2,1) outranks `.ux-utabs > [aria-selected="true"], .ux-utabs > [aria-current="page"]` (0,2,0), so
  the active pill loses its pink-soft-ink text while the pointer rests on it (right after a click, and on every
  hover). Proposed: `.ux-utabs > button:not([aria-selected="true"]):hover, .ux-utabs > a:not([aria-current="page"]):hover`
  (or raise the selected rule, e.g. `.ux-utabs > [aria-selected="true"]:is(*, :hover)`).
- Why: prototype `.utabs button.on` comes after `.utabs button:hover` with the same specificity, so the selected
  tab keeps `--pink-soft-ink` on hover. Found by `e2e/ux-v1/p10.spec.ts` (styles.json `.utabs button.on`
  color / border-top-color mismatch right after clicking the Badges tab); the spec now measures with the
  pointer moved away.
- Prototype state: `passport-badges` (also `community`, `leaderboard`, any tab row).

## 2. (info, no change needed) HeaderPictureSheet wiring

- The sheet is used as is by P10 (`components/profile/ux-v1/header-picker.tsx`): `onFile` / `onLink` go to
  `POST /api/profile/header/upload` / `POST /api/profile/header/link`, `onThemeColour` clears `header_url` through
  `/api/auth/update-profile`. Its errors, busy state, focus trap and three closings are covered by the P10 spec.

## 3. Tab bar "You" for a guest: open the guest passport, as the prototype does

- What: `src/components/layout/ux-v1/ux-tab-bar.tsx` prevents the "You" link for a guest and opens the sign-in
  sheet. Now that `/me` (and `/profile`, which redirects to it) renders the guest passport under the flag
  (X1-004, branch `ux11/p10-fix2`), the tab can simply follow its `href` for everyone (drop the `guest`
  interception), so a guest lands on the invitation (mascot, "Your K-pop passport", Sign in, "Play a quiz first").
- Why: prototype tab bar `<a class="tab" data-tab="you" onclick="go('you')">` shows view "you" for every
  visitor; signed out, that view is `#you section[data-auth=out]` (AUDIT-X1 X1-004 names "A0 for the tab bar").
  The avatar menu is signed-in only, so the nav is not concerned.
- Prototype state: `go('you')` with `body.guest` (P10 reference `passport-guest`, `v11/reports/P10/proto-styles.json`).
