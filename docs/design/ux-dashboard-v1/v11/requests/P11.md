## 3. A0 (FYI, no change needed): Enter in the search field

- What: P11's `SearchResults` handles Enter while a result row is highlighted (the first row by default, or the
  row moved to with the arrows / the pointer): it opens that row and calls `onNavigate()`. When there is no row
  (no results, a failed read, or rows of an older query still on screen) it does nothing and the host's
  `submit` (to `/search?q=`) runs as today. ArrowDown in the field moves focus into the rows.
- Why: WIRING-MAP v10 "Search overlay ... Enter opens first" and the prototype's keydown (`Enter` clicks the
  first `.srow`). The slot has no key prop, so P11 listens on the document (capture) for keys whose target is
  `#ux-sq`, and never touches the host's markup.
- Optional for A0: the default hint "Press Enter to see every result" is replaced by P11's rows; if A0 wants
  full combobox semantics (role=combobox, aria-controls, aria-activedescendant on `#ux-sq`), P11 can expose
  the row ids.
- State: `search`.
