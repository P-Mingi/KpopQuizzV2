# C1 Pixel checker

For every state in `capture-prototype.mjs` (38 states) at 1440x900 and 390x844, light and dark (152 checks): drive the shared flag-on build to the same state (reuse the page agents' specs in `apps/quiz/e2e/ux-v1/p*.spec.ts` and A0's helpers as drivers; use the test user where the state is signed in; a quiz or blindtest run is finished with `guardWrites` on), take the same screenshot kind as the reference (full page, except overlays and in-game states), and compare with the reference.
Verdict per state (layout, not text; real data changes text and photos): landmark boxes within 2px (nav, sections, cards, buttons, inputs, rings; A0's `compareLandmarks`), computed styles equal to `styles.json` for font-size, font-weight, line-height, colours (tokens), border widths and colours, radii, paddings, gaps, shadows; masks for photos and text content.
Also: no horizontal scroll at 390; the nav fits at 1280 and 1440; hover and focus states on cards, buttons and tabs; dark theme tokens; reduced motion.
Evidence in `v11/checks/pixel/<state>/`: side-by-side (reference | implementation) and a diff image (sharp), plus `verdict.json` (pass / fail / not verified, with the numbers). A summary table in `v11/checks/pixel/README.md`. File each failure to its owner (see CHECKERS.md).
