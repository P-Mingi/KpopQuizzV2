## 2. Component API for the G agents

Import paths are from `apps/quiz/src`. Server-safe unless marked (client). Every class is `ux-` prefixed; none of
them existed in v11 (checked against every `styles/ux-v1/*.css` and every `ux-*` token in `src` on `feat/v12`).

Flag
- `@/lib/ux-v12`: `isUxV12(): boolean`. True only with `NEXT_PUBLIC_UX_V12` and `NEXT_PUBLIC_UX_V1` both `1` or
  `true`. Use it for every v12 page (`if (!isUxV12()) notFound()`), route and cron.

Team badge (SYSTEM.md 5.6)
- `@/components/ux-v1/person-name`: `PersonName({ ..., isTeam? })`. With `isTeam`: the name in the default ink, the
  Team pill right after it, and no accent, no name font, no bias tag even if they are passed.
- `@/components/ux-v1/post-card`: `PostCard({ ..., isTeam?, teamNote? })`. `isTeam`: team avatar (initial, pink
  ring, never a photo), Team pill, no flair. Pass the time alone as `meta` ("2 hours ago"): a team account has no
  level. `teamNote`: the line under the author (the post itself; the feed card does not show it).
- `@/components/ux-v1/avatar`: `UxAvatar({ name, size?, team? })`.
- `@/components/ux-v1/team`: `TeamTag()`, `TeamNote({ surface?: 'post' | 'profile' })`. `post` ends with "Replies come
  from fans." (prototype), `profile` is the SYSTEM.md sentence alone. Texts: `@/lib/ux-v1/a0/team`.
- All four ignore the prop unless `isUxV12()`. Classes: `ux-teamtag`, `ux-ava ux-ava-team`, `ux-teamnote`.

How to load a v12 page stylesheet
- Put it at `apps/quiz/src/styles/ux-v12/<id>.css` and do NOT import it (an import adds a `<link>` to flag-off
  pages, v11 decision 1). `buildUxStylesheet` serves every file of that folder, in name order after the v11 sheets,
  only when `isUxV12()`. It needs request R1 (one call in the route, ORCH's file). Nothing else to register.
- Prefix your classes with your id or a view name (`ux-live-...`, `ux-nta-...`); the v12 names above are taken.
- Dark values: follow the three token blocks of `a0.css` (light, `html.ux-v1.dark`, system dark).

E2E: `e2e/ux-v12/<id>.spec.ts` runs in the `ux-1440` and `ux-390` projects (same widths as `capture-v12.mjs`).
The landmark comparison of `a1.spec.ts` (`expected()`, `close()`, the `d | dk | m | mk` key) can be copied.

## 4. Flag gating

- Components: `isTeam` / `team` are ignored unless `isUxV12()`. The other pieces are new files that only v12 views
  import. The kit renders `<KitV12 />` only when `isUxV12()`.
- CSS: the v12 rules and tokens are one block at the end of `a0.css`, between `/* @ux-v12:begin */` and
  `/* @ux-v12:end */`. `buildUxStylesheet({ v12 })` cuts the block before minifying when the flag is off. Unit test:
  the v12-off output equals the old route algorithm run on an `a0.css` without the block. Measured on dev, with the
  route patched (R1): v11-only stylesheet 167,765 bytes, sha256 `ff7e12496f968335...` on the branch AND on the
  `feat/v12` base; both on: 180,626 bytes (12,861 more = the minified block).
