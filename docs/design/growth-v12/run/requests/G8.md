# Requests from G8 (Group hub + creators)

Every item is in a file G8 does not own. Paths are under `apps/quiz/`. G8's helpers:
`src/lib/creators/link-plays.ts` (`LINK_COOKIE`, `LINK_COOKIE_MAX_AGE`, `recordLinkPlay`, `readLinkPlays`), pure and
unit tested with a fake store. Nothing here is needed for the flag-off site; every item is inert until its flag or SQL.

## R1. Remember the share code on the click (owner: nobody in OWNERSHIP.json, ORCH assigns)

- File: `src/app/api/share/click/[code]/route.ts`.
- Why: "plays from your link" in the share kit (SYSTEM.md 5.4) needs to know that a play came through a creator's
  `/s/<code>` link. Today the click is counted and the visitor is sent to `/q/<slug>`; nothing travels with them.
- What: only when `isUxV12()`, on the final redirect when `link` was found, set the cookie:
  ```ts
  const res = NextResponse.redirect(redirectUrl, { status: 302 });
  if (isUxV12() && isShareCode(shareCode)) {
    res.cookies.set(LINK_COOKIE, shareCode, { maxAge: LINK_COOKIE_MAX_AGE, httpOnly: true, sameSite: 'lax', secure: true, path: '/' });
  }
  return res;
  ```
  (`isShareCode`, `LINK_COOKIE`, `LINK_COOKIE_MAX_AGE` from `@/lib/creators/link-plays`, `isUxV12` from `@/lib/ux-v12`.)
  No new write; flag off the response is byte for byte today's.

## R2. Record the play that came through the link (owner: nobody, ORCH assigns)

- File: `src/app/api/quiz/[id]/play/route.ts`, after `record_play` succeeded.
- What, only when `isUxV12()`:
  ```ts
  const code = request.cookies.get(LINK_COOKIE)?.value;
  if (code) {
    void recordLinkPlay(createServiceRoleClient(), {
      code, quizId: id, playerId: playerId ?? null, anonId: anonId ?? null,
      isTest: process.env.VERCEL_ENV !== 'production',
    });
  }
  ```
  `recordLinkPlay` never throws, skips the link's owner, another quiz and an unknown code, and answers `not_live`
  (no write) until `docs/pending-migrations/v12-g8-share-link-plays.sql` is applied. One row per link, player and
  UTC day; the player is stored as a 32 hex hash only.
- Until R1, R2 and the SQL are in, the share kit simply has no "plays from your link" line (rule 7).

## R3. Create reads `?type=` (owner: G1 for `create-funnel.tsx`; `app/(site)/create/page.tsx` and `lib/ux-v1/p5/**` are nobody's)

  guess_from_clues` ("3 templates, Create prefilled"). Today Create honours `?group=` only, so a template opens Create

  `quiz_type: type` and `questions: [blankQuestionFor(type)]` (a saved draft still wins, as for the group).
