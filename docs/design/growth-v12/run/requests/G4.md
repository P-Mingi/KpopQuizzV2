# Requests from G4 (Live blindtest)

Everything here is in a file G4 does not own. Each item: what, why, which file, what to write. Paths under
`apps/quiz/` unless said otherwise.

## R1. Cron line for the room expiry (owner: ORCH, `vercel.json`)
- What: add to `crons`:
  ```json
  { "path": "/api/cron/live-expire", "schedule": "*/30 * * * *" }
  ```
- Why: rooms older than two hours are emptied by `GET /api/cron/live-expire` (test rooms deleted with their
  players and answers; real rooms keep one closed row with no question, token or player).
- Not urgent and not on the critical path: the two hours are enforced on every read and write by the SQL
  functions (an expired room is "gone" for every route, and its code can be given again at once), so the cron only
  cleans up. If the Vercel plan only allows daily crons, `"15 3 * * *"` works too: expired rooms just stay in the
  table (closed for every route) until the nightly run.
- The route needs `CRON_SECRET` (already used by every other cron), answers 401 without it, does nothing with the
  v12 flag off and answers 503 `not_live` until `v12-g4-live.sql` is applied.

## R2. Nav: `/live` and `/join` belong to Blindtest (owner: A1, `src/lib/ux-v1/a0/nav.ts`)
- What: `activeNav('/live')` and `activeTab('/live')` return the Blindtest item (prototype `NAVMAP` /
  `TABMAP`: `livegame: 'blindtest'`). `/join` hides the nav (focus shell), so it only matters for `/live`.
- Why: today no nav pill is active on `/live` (capture `run/reports/G4/shots/d-live-setup.png`); the reference
  shows the Blindtest pill active.

## R3. A QR encoder exists now (for A1's story image and G8's share kit)
- What: `src/lib/live/qr.ts`, no dependency, unit tested, and read back by an independent reader (report section 5).
  `qrDataUrl(text)` gives an SVG `data:` URL that `storyCardFile({ qr })` and `<StoryPreview qr>` take as is;
  `encodeQr(text)` + `qrPath(qr, quiet)` give the matrix and one SVG path; `components/live/qr-code.tsx`
  (`LiveQr({ text, label })`) is the inline SVG the lobby uses.
- Limits: byte mode, versions 1 to 10 (213 bytes at level M, 119 at H): enough for any site URL. A longer text
  throws.
- Nothing to do for G4; A1 can close its "QR tile of the story PNG not verified" item with a real code.

## R4. Deep link into a live room setup (owners: G3 theme pages and hub band, G8 group hubs)
- What: `/live` reads `?playlist=<generate playlist id>&name=<label>`. A known id (`all`, `gg`, `bg`, `5th-gen`)
  is selected; any other id (a group slug, a themed playlist once G2's are served by generate) is added as the
  first option with the given label. Example: `/live?playlist=stray-kids&name=Stray%20Kids`.
- Why: the prototype's "Play it live" buttons on a playlist or group page open the setup on that playlist.
- If the playlist has too few songs, generate answers 400 and the screen says so; nothing breaks.
