# Requests from G9 (Editorial seeding)

Everything here is in a file G9 does not own. Paths are under `apps/quiz/`. The helpers G9 ships:

- `src/lib/editorial/accounts.ts` (server): `getTeamIds(): Promise<Set<string>>`, `getTeamMap()`,
  `isEditorialUser(userId): Promise<boolean>`, `withoutTeam(rows, teamIds, (row) => userId)`. Cached 5 minutes.
  They answer "nobody" (and read nothing) with the v12 flag off, before the SQL is applied, and on a read error,
  so a call is safe everywhere and changes nothing until the owner inserts the accounts.
- SQL, once `v12-g9-editorial.sql` is applied: `public.is_editorial(uuid) returns boolean` (active accounts), for
  an exclusion that has to live in a view or an RPC.
- A1's props: `PersonName isTeam`, `UxAvatar team`, `TeamTag`, `TeamNote surface="profile"`.

The file and function names below were collected by a grep pass over the tree at `c38668a`; line numbers were
not rechecked one by one, so match on the function name.

## R1. Cron line (owner: ORCH, `vercel.json`)

Add to `crons`:

```json
{ "path": "/api/cron/editorial-publish", "schedule": "*/15 * * * *" }
```

The route exists (`src/app/api/cron/editorial-publish/route.ts`): 404 with the v12 flag off, 401 without

It publishes at most one item per run. `src/lib/vercel-config.test.ts` pins the cron list: it may need the line.

## R5g. Search page People rows (owner: G1, `src/app/(site)/search/page.tsx`)

The `profiles` query and `PersonRow` show a level, a title and a follower count. For an editorial account: the
Team pill instead of the level and title (`getTeamIds()` on the row ids; the select needs `id`). The v11 search
overlay (G9's `p11`) lists groups, quizzes and songs only: no person, nothing to badge there.

## R6. This or that splits for the weekly recap (owner: G7)

`src/lib/editorial/template-data.ts` `readWeeklyRecap` returns `splits: []` because G7's module is not on this
branch. Wanted: a server read in `src/lib/duel/` returning, for the last 7 full UTC days,
`{ question: string; a: string; b: string; votesA: number; votesB: number }[]` (real votes only, most voted first).
G9 then calls it inside its `soft()` wrapper: no data = the recap has no such line. `buildWeeklyRecap` already
renders the line and its source (unit tested).

## R7. A v12 sheet for G9 (owner: ORCH, optional)

`OWNERSHIP.json` gives G9 `styles/ux-v1/p8.css` but no `styles/ux-v12/g9.css`. A v12 rule in `p8.css` cannot be
cut for a v11-only build without breaking A1's `ux-v12.test.ts` (it expects every sheet but `a0.css` to be served
whole), so G9 added no rule at all: the Sources list of an editorial post and the admin preview frame use inline
styles. If the owner wants them as classes, add the glob `apps/quiz/src/styles/ux-v12/g9.css` to G9.
