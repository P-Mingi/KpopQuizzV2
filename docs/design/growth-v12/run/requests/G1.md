## A. Blindtest tracking

### R1. Ranked runs are not recorded (owner: nobody in OWNERSHIP.json, ORCH assigns)
- File: `src/components/ranked/ux-v1/use-ranked-run.ts`.
- Why: the brief says ranked is wired through `use-run.ts` with `mode='ranked'`, but ranked has its own hook
  (`useRankedRun`) and never goes through `useBlindtestRun`. G1 cannot edit it, so ranked runs are the one v11
  flow that does not reach `bt_runs` today.
- What: the same four calls as the legacy games, through the hook G1 already ships
  (`src/components/blind-test/use-bt-tracking.ts`):
  `const tracking = useBtTracking();` then
  `tracking.open({ kind: 'free', playlist: 'ranked', mode: 'ranked', rounds: 10 })` when the run is issued,
  `tracking.attach(audioRef.current)` after each `loadAndPlay`, `tracking.answer({ song_id, kind, correct, ms })`
  after each server reveal (use `RoundReveal.song` id if the server returns one; the placeholder `round-N` ids are
  dropped by the server, the counts are kept), `tracking.finish(true)` on results and `tracking.finish(false)` in
  quit. It records `playlist = 'theme:ranked'`, `mode = 'ranked'`, source from the page (`other` on
  `/blindtest/ranked`). Nothing else changes.

### R2. Challenge code passed explicitly (owner: G3)
- File: `src/components/blindtest/ux-v1/controller.tsx` line 108.
- Why: `startChallenge(questions, pick)` does not know the link code. `use-run.ts` reads `?c=` on mount before the
  controller strips it, which covers a page loaded on the link (the e2e proves `challenge:KQ7P2X`). A challenge
  opened by client navigation after the hook mounted would record `challenge:unknown`.
- What: `run.startChallenge(v.questions, { playlist: v.playlist, label: v.label }, v.code);` (the third argument
  is optional and already in the `RunApi` type).

### R3. Source of the landings, group hubs, live (owners: G3 landings, G8 group hubs, G4 live)
- Why: `btSourceFor()` in `src/lib/tracking/bt-shared.ts` maps the page path to `bt_runs.source`. It already knows
  `/guess-the-kpop-song`, `/fr/blind-test-kpop`, `/es/adivina-la-cancion-kpop`, `/id/tebak-lagu-kpop`
  (`landing-*`), `/groups/<slug>` (`group-hub`), `/live` and `/join` (`live`), `/blindtest` and `/pt/blindtest`
  (`hub`), `?ref=share` (`share`). Anything else is `other`.
- What: nothing to do if your page lives on one of those paths and plays through `useBlindtestRun` or the legacy
  game. If a blindtest starts from another path (a group hub that is not under `/groups/`, a themed playlist
  page that should count as `hub`), tell G1 the path and the source it should map to. Live rooms: call
  `trackBtRun` yourself with `playlist: 'live:<room>'`, `source: 'live'`.

### R4. Playwright project for `e2e/ux-v12/` (owner: A1, `playwright.config.ts`)

### R5. v11 blindtest specs with the tracking switch on (owner: ORCH / checkers)
