`src/lib/editorial/surfaces/quiz-rank.ts` (tested in `quiz-rank.test.ts`) and the SQL
`docs/pending-migrations/v12-f5-quiz-rank.sql` (new names `get_quiz_rank_v12` and `get_quiz_rank_for_score_v12`,

reverted it; it is not in any F5 commit).
